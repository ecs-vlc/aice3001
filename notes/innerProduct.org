* Keywords
  * Inner-product, operators

* Main Points
   * For some vector spaces we can define an /inner product/ between
     pairs of vectors
   * Inner products are scalars associated with two elements in a vector space
   * They are generally denoted by $\langle\bm{x},\bm{y}\rangle$
   * To be an inner-product requires satisfying 5 axioms
     1. $\inner{\bm{x}}{\bm{x}} \geq 0$ for all $\bm{x}\in\mathcal{V}$
     2. $\inner{\bm{x}}{\bm{x}} = 0$  if and only if $\bm{x}=\bm{0}$
     3. $\inner{\alpha\, \bm{x}}{\bm{y}} = \alpha\, \inner{\bm{x}}{\bm{y}}$
     4. $\inner{\bm{x}}{\bm{y}+\bm{z}} = \inner{\bm{x}}{\bm{y}} +
        \inner{\bm{x}}{\bm{z}}$
     5. $\inner{\bm{x}}{\bm{y}} = \inner{\bm{y}}{\bm{x}}$
   * The inner-product induces a norm: $\len{x} = \sqrt{\inner{\bm{x}}{\bm{x}}}$
   * For normal vectors (i.e. $\bm{x}\in\mathbb{R}^{n}$) the standard inner product is the dot-product
     \begin{align*}
	 \langle \bm{x}, \bm{y} \rangle = \bm{x}^\tr\bm{y} = \sum_{i=1}^n x_i\,y_i
     \end{align*}
   * We can define an inner product between functions
     \begin{align*}
       \langle f, g \rangle = \int_{x\in\mathcal{I}} f(x)\,g(x)\,\dd x
     \end{align*}
   * For matrices we can define the Frobenius inner-product
     \begin{align*}
       \inner{\mat{A}}{\mat{B}}_{F} = \mathrm{Tr}\, \mat{A}^{\tr}\,\mat{B} = \sum_{i,j} A_{ij} \, B_{ij}
     \end{align*}
     which defines the Frobenius norm 
     \begin{align*}
     \len{\mat{A}}_{F} = \sqrt{\inner{\mat{A}}{\mat{A}}_{F}} = \sqrt{ \sum_{i,j} A_{ij}^{2}}
     \end{align*}
     The Frobenius norm is compatible with the Euclidean norm
     ($\len{\mat{A}\bm{x}} \leq \len{\mat{A}}_{F}\len{\bm{x}}$), but it is
     not /induced/ by any vector norm, unlike the spectral norm.
   * A really important inequality is the /Cauchy-Schwarz/ inequality
           \begin{align*}
        \inner{\bm{x}}{\bm{y}}^2 \leq \inner{\bm{x}}{\bm{x}} \,
        \inner{\bm{y}}{\bm{y}} = \len{\bm{x}}^2\,\len{\bm{y}}^2
      \end{align*}
   * Inner products allow us to define the notion of similarity
     \begin{align*}
	 \langle \bm{x}, \bm{y} \rangle &= \|\bm{x}\| \, \|\bm{y}\| \, \cos(\theta) \\
	 \langle f(x), g(x) \rangle &= \|f(x)\| \, \|g(x)\|\, \cos(\theta)
     \end{align*}
   * $\cos(\theta)$ can be seen as a measure of the correlation
     between vectors (or functions)
   * Because of Cauchy-Schwarz $\langle \bm{x}, \bm{y}
     \rangle/(\|\bm{x}\| \, \|\bm{y}\|)$ lies between -1 and 1 (so
     that we can represent this quantity by the cosine of an angle)

** Coordinates or Basis Vectors
   * Any set of vectors that span the entire vector space can be
     considered a set of basis vectors or coordinates
   * If our bases are linearly independent then we have a set of
     non-degenerate basis functions where each vector is unique
   * The most convenient set of basis vectors are those where the
     bases are normalised and orthogonal
     $\langle\bm{b}_i,\bm{b}_j\rangle=\delta_{ij}$
   * *Basis Functions*
     * For a function space we can consider a set of basis functions
     * A familiar set of functions define on the interval $[0,2\,\pi]$
       are the Fourier functions 
       $$ \{1,\, \cos(\theta),\, \sin(\theta),\, \cos(2\,\theta),\,
       \sin(2\,\theta),\, \cdots\} $$
     * This set is orthogonal: $\langle b_i(\theta),\,b_j(\theta)\rangle = 0$
       whenever $i \neq j$.  It is not normalised --- for example
       $\langle 1,1\rangle = 2\pi$ while $\langle \cos\theta,\cos\theta\rangle
       = \pi$ --- so divide each by its own norm to get an /orthonormal/ set
     * There are many orthogonal polynomials that have similar properties
     * Given an /orthonormal/ set of functions $\{b_i(\bm{x})\}$ we can decompose a function $f(\bm{x})$
       as an (infinite) vector $\bm{f}$ with components $f_i = \langle f(\bm{x}),b_i(\bm{x})\rangle$.
       If the set is orthogonal but not normalised the components are
       $f_i = \langle f,b_i\rangle/\langle b_i,b_i\rangle$
     * This allows us to represent any function as a point in an infinite-dimensional space
     
** Projection Operators
   * Given a vector $\bm{a}$ we can ask how much of it lies along another
     vector $\bm{b}$
     \begin{align*}
       \mathrm{proj}_{\bm{b}}(\bm{a}) =
       \frac{\inner{\bm{a}}{\bm{b}}}{\inner{\bm{b}}{\bm{b}}}\, \bm{b}
     \end{align*}
   * Read this as two steps: the scalar
     $\inner{\bm{a}}{\bm{b}}/\inner{\bm{b}}{\bm{b}}$ says how many copies of
     $\bm{b}$ are needed, and multiplying by $\bm{b}$ puts the answer back in
     the direction of $\bm{b}$
   * If $\bm{b}$ is normalised ($\len{\bm{b}}=1$) this is just
     $\inner{\bm{a}}{\bm{b}}\,\bm{b}$
   * Using $\inner{\bm{a}}{\bm{b}} = \len{\bm{a}}\len{\bm{b}}\cos(\theta)$ the
     length of the projection is $\len{\bm{a}}\cos(\theta)$, which is the
     picture you would draw
   * The defining property of a projection is that doing it twice changes
     nothing --- it is /idempotent/
     \begin{align*}
       \mathrm{proj}_{\bm{b}}\bra{\mathrm{proj}_{\bm{b}}(\bm{a})}
       = \mathrm{proj}_{\bm{b}}(\bm{a})
     \end{align*}
     which follows because $\mathrm{proj}_{\bm{b}}(\bm{a})$ already points
     along $\bm{b}$, so projecting it again leaves it alone
   * The *remainder* is what matters for what follows: $\bm{a} -
     \mathrm{proj}_{\bm{b}}(\bm{a})$ is orthogonal to $\bm{b}$, since
     \begin{align*}
       \inner{\bm{a} - \frac{\inner{\bm{a}}{\bm{b}}}{\inner{\bm{b}}{\bm{b}}}
       \bm{b}}{\bm{b}} = \inner{\bm{a}}{\bm{b}} -
       \frac{\inner{\bm{a}}{\bm{b}}}{\inner{\bm{b}}{\bm{b}}}
       \inner{\bm{b}}{\bm{b}} = 0
     \end{align*}
   * For vectors in $\mathbb{R}^n$ the projection is a matrix,
     $\mat{P} = \bm{b}\,\bm{b}^\tr/(\bm{b}^\tr\bm{b})$, and idempotency reads
     $\mat{P}^2 = \mat{P}$
   * To project onto a whole subspace spanned by an orthonormal set
     $\{\bm{e}_1,\ldots,\bm{e}_k\}$ just add the projections,
     $\mat{P} = \sum_{i=1}^k \bm{e}_i \bm{e}_i^\tr$.  This is the operator
     that appears again in PCA

** Gram-Schmidt Orthogonalisation
   * Projections let us turn any set of linearly independent vectors
     $(\bm{a}_1,\ldots,\bm{a}_n)$ into an orthonormal basis
   * Take each vector in turn and subtract off everything it shares with the
     directions already found; normalise what is left
     \begin{align*}
       \bm{u}_1 &= \bm{a}_1,
       & \bm{e}_1 &= \frac{\bm{u}_1}{\len{\bm{u}_1}} \\
       \bm{u}_2 &= \bm{a}_2 - \mathrm{proj}_{\bm{u}_1}(\bm{a}_2),
       & \bm{e}_2 &= \frac{\bm{u}_2}{\len{\bm{u}_2}} \\
       \bm{u}_3 &= \bm{a}_3 - \mathrm{proj}_{\bm{u}_1}(\bm{a}_3)
                            - \mathrm{proj}_{\bm{u}_2}(\bm{a}_3),
       & \bm{e}_3 &= \frac{\bm{u}_3}{\len{\bm{u}_3}}
     \end{align*}
     and in general $\bm{u}_k = \bm{a}_k - \sum_{i<k}
     \mathrm{proj}_{\bm{u}_i}(\bm{a}_k)$
   * *The projections are onto the $\bm{u}_i$, not the $\bm{a}_i$.*  This is
     the easy mistake.  Subtracting $\mathrm{proj}_{\bm{a}_2}(\bm{a}_3)$
     instead of $\mathrm{proj}_{\bm{u}_2}(\bm{a}_3)$ does /not/ leave
     something orthogonal to both, because $\bm{a}_2$ is not itself
     orthogonal to $\bm{a}_1$.  Only $\bm{u}_2 = \bm{a}_2$ when $k=2$, which
     is why the second step looks the same either way
   * Each $\bm{u}_k$ is orthogonal to everything before it by construction:
     it is a remainder, and we showed above that remainders are orthogonal to
     what was subtracted
   * If the $\bm{a}_i$ are /not/ linearly independent some $\bm{u}_k$ comes
     out as $\bm{0}$, and the process tells you the set was degenerate
   * The same algorithm works in any inner-product space.  Applied to
     $1, x, x^2, \ldots$ with $\inner{f}{g} = \int f g \,\dd x$ it generates
     the orthogonal polynomials
   * In $\mathbb{R}^n$ it is numerically poor: rounding errors accumulate and
     the later vectors drift away from orthogonality.  Numerical libraries
     compute the same factorisation with Householder reflections instead.
     Gram-Schmidt is how you /understand/ the result, not how you compute it

** Operators
   * Operators transform elements of a vector space
   * Consider the transformation or operator $\mathcal{T}: \mathcal{V} \rightarrow \mathcal{V}'$
   * This says that $\mathcal{T}$ maps some object
     $\bm{x}\in\mathcal{V}$ to an object $\bm{y}=\mathcal{T}[\bm{x}]$
     in a new vector space $\mathcal{V}'$
   * *Linear Operators*
     * Linear operators satisfy the two conditions
       1. $\mathcal{T}[a\,\bm{x}] = a\,\mathcal{T}[\bm{x}]$
       2. $\mathcal{T}[\bm{x} + \bm{y}] = \mathcal{T}[\bm{x}] + \mathcal{T}[\bm{y}]$
     * Linear operators are really important because we can understand them
     * For normal vectors the most general linear operation is
       \begin{align*}
         \mathcal{T}[\bm{x}] = \mat{M}\,\bm{x}
       \end{align*}
       where $\mat{M}$ is a matrix
     * For functions the most general linear operator is a kernel function
       \begin{align*}
          g(\bm{x}) = \mathcal{T}[f(\bm{x})] = \int
          K(\bm{x},\bm{y})\, f(\bm{y}) \, \dd \bm{y}
       \end{align*}
       * Kernels appear in SVMs, SVRs, kernel-PCA, Gaussian Processes
   * Often we are interested in operators that map vectors in a vector space to new
     vectors in the same vector space
     * $\mathcal{T}: \mathcal{V}\rightarrow\mathcal{V}$
     * The most general linear mapping for normal vectors that does this is a square matrix
** Matrices and Mappings
   * Matrices, $\mat{M}$ are linear maps from one point $\bm{x}$ to
     another $\bm{y}=\mat{M}\bm{x}$
   * The product of a matrix $\mat{C}  = \mat{A}\mat{B}$ corresponds
     to applying the mapping $\mat{B}$ followed by $\mat{A}$
   * For most matrices $\mat{A}\mat{B} \neq \mat{B}\mat{A}$ (we say
     matrix multiplication does not commute)
   * There are pairs of matrices that do commute, but they need to
     share a special structure for this to happen
   * Matrix multiplication is associative.  That is, $(\mat{A}\,\mat{B})\mat{C} = \mat{A} (\mat{B}\, \mat{C})$
