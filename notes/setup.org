# Every note pulls this in with
#     #+SETUPFILE: setup.org
# instead of repeating the whole block, which is what the comp6208 notes did
# (29 copies, which had already drifted apart -- see the note on \normal and
# \eq below).
#
# Three macros were defined inconsistently across the old notes:
#   \normal   28 notes take two arguments, gaussianProcesses took one
#   \eq       28 notes number with \arabic, gaussianProcesses with \alph
#   \logg     only generativeModels added a \strut
# The majority version is here; gaussianProcesses.org redefines its two
# locally, just after this line, the way the problem sheets keep \ml and \mm
# local rather than forcing them into macros.tex.

# --- beamer leftovers ------------------------------------------------------
# Much of this material was lifted from the lecture slides, which carry
# \pause to build up an overlay. It means nothing in a printed note, and
# article has no definition for it, so every occurrence was a LaTeX error.
# Defining it away is less invasive than editing it out of 7 notes.
#+LATEX_HEADER: \newcommand{\pause}{}

# --- deep bullet lists -----------------------------------------------------
