* Keywords
  * Fields, vector spaces, metrics, Lipschitz functions, norms, spectral norm, regularisation

* Main Points

** Scalars (Fields)
   * A vector space is built over a set of /scalars/, formally a /field/:
     numbers we can add, subtract, multiply and divide (except by $0$)
     with the usual rules
   * The rationals, the reals and the complex numbers are fields.  The
     integers are not, since $2$ has no integer inverse
   * We will almost always use the reals

** Vector Spaces
   * A set of objects $\mathcal{V}$, with addition and multiplication by a
     scalar, is a /vector space/ if
     1. $a\,\bm{v}\in\mathcal{V}$ and $\bm{v}+\bm{w}\in\mathcal{V}$ for
        all $\bm{v},\bm{w}\in\mathcal{V}$ (closure)
     2. $\bm{v}+\bm{w} = \bm{w}+\bm{v}$ (commutativity of addition)
     3. $(\bm{u}+\bm{v})+\bm{w} = \bm{u}+(\bm{v}+\bm{w})$ (associativity of addition)
     4. $\bm{v}+\bm{0} = \bm{v}$ (additive identity $\bm{0}$)
     5. $\bm{v}+(-\bm{v}) = \bm{0}$ (additive inverse $-\bm{v}$)
     6. $1\,\bm{v} = \bm{v}$ (multiplicative identity)
     7. $a\,(b\,\bm{v}) = (a\,b)\,\bm{v}$ (associativity of scalar multiplication)
     8. $a\,(\bm{v}+\bm{w}) = a\,\bm{v}+a\,\bm{w}$ and
        $(a+b)\,\bm{v} = a\,\bm{v}+b\,\bm{v}$ (distributivity)
   * Most of these hold automatically if addition and scalar
     multiplication behave like ordinary arithmetic.  The one to watch
     is closure: adding two members, or scaling one, must not take you
     outside the set
   * Column vectors in $\mathbb{R}^n$, matrices of a fixed shape,
     infinite sequences and functions on an interval all form vector
     spaces.  Anything satisfying the axioms is a "vector"
   * Bounded vectors (say $\len{\bm{v}}\leq1$) do /not/ form a vector
     space: $2\,\bm{v}$ may fall outside the set

** Distances (Metrics)
   * A /distance/ or /metric/ satisfies 4 conditions
     1. $d(\bm{x},\bm{y})\geq0$ (non-negativity)
     2. $d(\bm{x},\bm{y}) = 0$ if and only if $\bm{x}=\bm{y}$ (identity of indiscernibles)
     3. $d(\bm{x},\bm{y}) = d(\bm{y},\bm{x})$ (symmetry)
     4. $d(\bm{x},\bm{y}) \leq d(\bm{x},\bm{z}) + d(\bm{z},\bm{y})$ (triangular inequality)
   * You can define different distances for the same set of objects
     (e.g. Euclidean and Manhattan distance)
   * Often we use /pseudo-metrics/ that break one or other of the
     conditions

** Mappings and Lipschitz Functions
   * A function $f:\mathcal{V}\rightarrow\mathcal{W}$ maps one vector
     space to another (possibly the same one).  Mappings compose: for
     matrices, $\mat{A}\,\mat{B}\,\bm{x} = \mat{A}\,(\mat{B}\,\bm{x})$
     means "apply $\mat{B}$, then $\mat{A}$"
   * A useful measure of how much a mapping can amplify changes is the
     /Lipschitz condition/: $f$ is \(K\)-Lipschitz if, for all $x$ and $y$,
     \begin{align*}
      d(f(x), f(y)) \leq K\, d(x,y)
     \end{align*}
     for some fixed $K<\infty$
     * Lipschitz functions are continuous (they have no jumps), but not
       every continuous function is Lipschitz: $\sqrt{x}$ on $[0,1]$ is
       continuous but infinitely steep at $0$
     * For a differentiable $f:\mathbb{R}\rightarrow\mathbb{R}$, the
       smallest $K$ is the largest value of $|f'(x)|$
   * If $K<1$ the mapping is /contractive/.  The /Banach fixed-point
     theorem/ says a contractive mapping (of $\mathbb{R}^n$, or any
     complete metric space, into itself) has exactly one fixed point
     $x^*=f(x^*)$, and iterating $x_{t+1} = f(x_t)$ from any start
     converges to it.  Each step shrinks the distance to $x^*$ by at
     least a factor $K$:
     $d(x_{t+1},x^*) = d(f(x_t),f(x^*)) \leq K\,d(x_t,x^*)$.  This is a
     standard way to prove that an iterative algorithm converges

** Norms
   * Norms provide a measure of the size of a vector.  They satisfy
     three conditions
     1. $\| \bm{v} \| >0$ if $\bm{v}\neq\bm{0}$ and $\|\bm{0}\|=0$ (non-negativity)
     2. $\| a\,\bm{v} \| = |a|\, \| \bm{v} \|$ ("linearity")
     3. $\| \bm{u} + \bm{v} \| \leq \| \bm{u} \| + \| \bm{v} \|$ (triangular inequality)
   * If not all of these conditions hold we have a /pseudo-norm/
   * *Vector norms*
     * Common examples
       1. Euclidean or 2-norm: $\| \bm{v} \|_2 = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$
       2. \(p\)-norm ($p\geq1$): $\| \bm{v} \|_p = \left(\sum_{i=1}^n | v_i |^p \right)^{1/p}$
       3. 1-norm: $\| \bm{v} \|_1 = \sum_{i=1}^n | v_i |$
       4. \(\infty\)-norm or max-norm: $\| \bm{v} \|_{\infty} = \max_i |v_i|$
     * The 1-, 2- and \(\infty\)-norms are all \(p\)-norms
     * The "0-norm", the number of non-zero components, is only a
       pseudo-norm, as $\|2\,\bm{v}\|_0 = \|\bm{v}\|_0 \neq 2\,\|\bm{v}\|_0$
   * *Norms for regularisation.*  When many weight vectors $\bm{w}$ fit
     the training data equally well we usually prefer a "small" one, so
     we minimise $\mathrm{loss}(\bm{w}) + \eta\,\len{\bm{w}}$.  This is
     equivalent to minimising the loss subject to $\len{\bm{w}}\leq c$:
     confining $\bm{w}$ to a /ball/ of the chosen norm.  Each norm means
     something different by small
     * $\len{\bm{w}}_2$ small: no component is large; the weight is spread out
     * $\len{\bm{w}}_1$ small: a few large components are tolerated if the
       rest are tiny.  The 1-norm ball is a diamond with corners on the
       axes, and the optimum often lands on a corner where most
       components are exactly zero.  This is why $L_1$ regularisation
       (the /lasso/) picks out a few features
     * $\len{\bm{w}}_\infty$ small: only the largest component is controlled
     * Choosing a norm is choosing what you mean by "small"
   * *Matrix norms*
     * Examples
       1. The Frobenius norm is \(\| \mat{A} \|_F = \sqrt{\sum_{i=1}^m \sum_{j=1}^n |A_{ij}|^2}\)
       2. The /spectral norm/ is the largest factor by which $\mat{A}$ can
          stretch a vector
          \begin{align*}
          \len{\mat{A}}_2 = \max_{\bm{v}\neq\bm{0}}
          \frac{\len{\mat{A}\,\bm{v}}_2}{\len{\bm{v}}_2}
          \end{align*}
          For a symmetric matrix this is its largest $|\lambda|$.  For a
          general matrix it is the largest singular value (see the SVD
          lecture), which can be bigger than any $|\lambda|$
       3. There are many others: the 1-norm, max-norm, nuclear norm, \ldots
     * The determinant is not a norm: it can be negative and does not
       scale correctly
     * Many (but not all) matrix norms satisfy
       \begin{align*}
         \| \mat{A}\,\mat{B} \| \leq \| \mat{A} \| \times \| \mat{B} \|
       \end{align*}
       which lets us bound the norm of a product quickly
     * A matrix norm $\len{\cdot}_a$ and a vector norm $\len{\cdot}_b$ are
       /compatible/ if
       \begin{align*}
         \| \mat{M} \bm{v} \|_b \leq \| \mat{M} \|_a \times \| \bm{v} \|_b
       \end{align*}
       The spectral and Euclidean norms are compatible; this is just the
       definition of the spectral norm.  The Frobenius and Euclidean
       norms are compatible too, since
       $\len{\mat{M}}_2 \leq \len{\mat{M}}_F$
     * The sensitivity of a mapping is measured by its /condition
       number/ $\len{\mat{M}}\,\len{\mat{M}^{-1}}$: the ratio of its
       largest to smallest stretch (see the eigensystems notes)

** The Lipschitz Constant of a Network
   * A deep network applies layers in turn.  Ignoring biases, a linear
     layer is $\bm{x}_n = \mat{L}_n\,\bm{x}_{n-1}$, interleaved with
     non-linearities such as ReLUs and pooling
   * Lipschitz constants multiply under composition: if $g$ is
     \(K_g\)-Lipschitz and $f$ is \(K_f\)-Lipschitz then
     $\len{f(g(\bm{x}))-f(g(\bm{y}))} \leq K_f\,\len{g(\bm{x})-g(\bm{y})}
     \leq K_f\,K_g\,\len{\bm{x}-\bm{y}}$
   * By compatibility, a linear layer has $K = \len{\mat{L}_n}_2$.  ReLUs
     and max-pooling never stretch distances (they can shrink them), so
     $K=1$.  Hence
     \begin{align*}
       K_{\mathrm{net}} \leq \prod_n \len{\mat{L}_n}_2
     \end{align*}
     This bound can be very loose (see Exercise 5)
   * *Why care?*  $\len{f(\bm{x}+\bm{\delta})-f(\bm{x})}\leq
     K\,\len{\bm{\delta}}$ bounds how much the output can move when the
     input is nudged
     * /Adversarial examples/ are tiny $\bm{\delta}$ that change the
       classification; a network with small $K$ is harder to fool
     * $K\gg1$ lets signals (and gradients) explode; $K\ll1$ lets them
       vanish
     * Wasserstein GANs need a critic with $K\leq1$.  One way to enforce
       this is /spectral normalisation/: divide each $\mat{L}_n$ by
       $\len{\mat{L}_n}_2$
     * Some bounds on how well a network generalises depend on $K$
     * But make $K$ too small and the network is too smooth to fit the data

** Function Norms
   * The most common function norms, for $f$ defined on a region $\mathcal{R}$, are
     1. The \(L_2\)-norm
	\begin{align*}
          \| f \|_{L_2} = \sqrt{\int_{\bm{x}\in\mathcal{R}} f^2(\bm{x}) \, \dd \bm{x}}
        \end{align*}
     2. The \(L_1\)-norm
	\begin{align*}
          \| f \|_{L_1} = \int_{\bm{x}\in\mathcal{R}} |f(\bm{x})| \, \dd \bm{x}
        \end{align*}
     3. The $\infty$ or max-norm
	\begin{align*}
          \| f \|_{\infty} = \max_{\bm{x}\in\mathcal{R}} |f(\bm{x})|
        \end{align*}
   * Function norms also define vector spaces: the $L_2$ space is the
     set of functions with $\| f \|_{L_2}<\infty$, and similarly for $L_1$
   * In these spaces two functions that differ only on a set of zero
     size (e.g. at a few isolated points) count as the same function, so
     that $\|f\|=0$ only for the zero function

** Norms and Metrics
   * Every norm induces a distance $d(\bm{x},\bm{y}) = \len{\bm{x}-\bm{y}}$,
     so every normed space is also a metric space (Exercise 6).  For
     example the Frobenius distance between matrices is
     $d_F(\mat{A},\mat{B}) = \len{\mat{A}-\mat{B}}_F$
   * Next lecture adds an /inner product/, which gives us angles as well
     as lengths

1. Which of these are vector spaces (with the usual addition and
   scalar multiplication)?  Give a reason
   1. Vectors in $\mathbb{R}^2$ with $x_1\geq0$
   2. Polynomials of degree at most 3
   3. Vectors in $\mathbb{R}^2$ with $x_1+x_2=0$
   4. Vectors in $\mathbb{R}^2$ with $x_1+x_2=1$
2. For $\bm{v}=(3,-4,0,1)^\tr$ compute $\len{\bm{v}}_1$,

3. Find a Lipschitz constant $K$, or show none exists, for
   1. $f(x) = 3x+1$ on $\mathbb{R}$
   2. $f(x) = \sin(x)$ on $\mathbb{R}$
   3. $f(x) = x^2$ on $\mathbb{R}$, and on $[-1,1]$
   4. $\mathrm{ReLU}(x) = \max(0,x)$ on $\mathbb{R}$
4. Show that $f(x) = x/2 + 1$ is contractive, find its fixed point,
   and iterate $x_{t+1} = f(x_t)$ from $x_0=0$.  How fast does the
   error shrink?
5. Let $\mat{L}_1 = \begin{pmatrix} 3 & 0 \\ 0 & 0.5 \end{pmatrix}$ and

   1. Find $\len{\mat{L}_1}_2$ and $\len{\mat{L}_1}_F$
   2. Compare $\len{\mat{L}_2\,\mat{L}_1}_2$ with the bound
      $\len{\mat{L}_2}_2\,\len{\mat{L}_1}_2$.  What does this say about
      the bound on $K_{\mathrm{net}}$?
6. Show that $d(\bm{x},\bm{y}) = \len{\bm{x}-\bm{y}}$ satisfies the four
   conditions for a metric

* Experiments

** Norms
   * In python, compare the spectral norm with the largest stretch of
     many random unit vectors, and with the largest eigenvalue

#+BEGIN_SRC python
import numpy as np

v = np.array([3, -4, 0, 1.0])
print([np.linalg.norm(v, p) for p in (1, 2, np.inf)])   # 1-, 2- and max-norms

rng = np.random.default_rng(0)
A = rng.normal(size=(3, 3))                  # not symmetric
u = rng.normal(size=(3, 100000))
u /= np.linalg.norm(u, axis=0)               # 100000 random unit vectors
print(np.linalg.norm(A @ u, axis=0).max())   # largest stretch found
print(np.linalg.norm(A, 2))                  # the spectral norm
print(np.abs(np.linalg.eigvals(A)).max())    # largest |eigenvalue|: smaller
print(np.linalg.norm(A, 'fro'))              # Frobenius norm: larger
#+END_SRC

   * The largest stretch found is (just below) the spectral norm, about
     1.82.  The largest $|\lambda|$ is only about 1.54: for a
     non-symmetric matrix the eigenvalues do not tell you how much it
     can stretch a vector

* Answers

1. Vector spaces?
   1. No: $(1,0)^\tr$ is in the set but $-1\times(1,0)^\tr$ is not
      (closure fails)
   2. Yes: sums and multiples of polynomials of degree at most 3 are
      polynomials of degree at most 3, and the zero polynomial is in
      the set
   3. Yes: if $x_1+x_2=0$ and $y_1+y_2=0$ then $(x_1+y_1)+(x_2+y_2)=0$
      and $a\,x_1+a\,x_2=0$.  It is a line through the origin
   4. No: it does not contain $\bm{0}$, and adding two members gives
      $x_1+x_2=2$
2. $\len{\bm{v}}_1 = 3+4+0+1 = 8$, $\len{\bm{v}}_2 = \sqrt{9+16+0+1} =
   \sqrt{26}\approx5.10$, $\len{\bm{v}}_\infty = 4$ and
   $\len{\bm{v}}_0 = 3$.  Indeed $4 \leq 5.10 \leq 8$
3. Lipschitz constants
   1. $|f(x)-f(y)| = 3\,|x-y|$, so $K=3$
   2. $|f'(x)| = |\cos(x)|\leq1$, so $K=1$ (by the mean value theorem
      $|\sin x - \sin y| = |\cos\xi|\,|x-y|$ for some $\xi$)
   3. $|x^2-y^2| = |x+y|\,|x-y|$ and $|x+y|$ is unbounded on
      $\mathbb{R}$, so no $K$ works.  On $[-1,1]$, $|x+y|\leq2$ so $K=2$
   4. $K=1$: if $x,y\geq0$ the difference is unchanged; if both are
      negative it becomes $0$; if $x\geq0>y$ then
      $|\mathrm{ReLU}(x)-\mathrm{ReLU}(y)| = x < x-y$.  ReLU never
      stretches but can shrink distances
4. $|f(x)-f(y)| = \tfrac12|x-y|$, so $K=\tfrac12<1$.  The fixed point
   solves $x = x/2+1$, i.e. $x^*=2$.  From $x_0=0$: $1, 1.5, 1.75,
   1.875, \ldots$.  The error $x^*-x_t = 2^{1-t}$ halves at every step,
   exactly the factor $K$
5. Spectral norms of layers
   1. A diagonal matrix stretches the $i$-th axis by $|L_{ii}|$, so
      $\len{\mat{L}_1}_2 = 3$, while $\len{\mat{L}_1}_F = \sqrt{9+0.25}
      \approx 3.04$
   2. $\mat{L}_2\,\mat{L}_1 = 1.5\,\mat{I}$, so $\len{\mat{L}_2\mat{L}_1}_2 =
      1.5$, but the bound gives $3\times3 = 9$.  Each layer stretches a
      different direction, and the second undoes the first.  The product
      bound on $K_{\mathrm{net}}$ is safe but can be very pessimistic
6. Non-negativity and $d=0 \Leftrightarrow \bm{x}=\bm{y}$ follow from
   norm condition 1.  Symmetry: $\len{\bm{x}-\bm{y}} =
   \len{(-1)(\bm{y}-\bm{x})} = |-1|\,\len{\bm{y}-\bm{x}}$.  Triangular
   inequality: $\len{\bm{x}-\bm{y}} = \len{(\bm{x}-\bm{z})+(\bm{z}-\bm{y})}
   \leq \len{\bm{x}-\bm{z}} + \len{\bm{z}-\bm{y}}$
